### 金额一致性（B 项核心断言，20 张全部通过）

- `unit_gross = round(unit_net + unit_tax, 2)`；
- `amount_net = round(unit_net × qty, 2)`；`tax_amount = round(unit_tax × qty, 2)`；
- `total_gross = amount_net + tax_amount`；
- 明细持久化 `unit_price/amount` 与价格快照一致；
- 整单 `subtotal = Σ明细金额`、`tax_amount = Σ明细税额`、`total = subtotal + tax_amount`；
- 20 张全部可复现；由 `cost_breakdown.unit_cost_raw + 冻结定价参数` 复算完全一致；
