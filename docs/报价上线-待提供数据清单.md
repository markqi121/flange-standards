# 报价功能上线 · 待提供数据清单（P0）

> 报价代码已具备上线条件。材料价/工资率已改为**动态报价参数**：价格库只提供默认值，
> 每张报价单可以填“本次实际价”，保存时冻结快照。因此不需要一张永久价目表，只需要
> 一组初始默认参数 + 20 张历史报价 UAT。
>
> 当前库内默认值仍是 `source=demo` 的演示数据，只能用于 UAT，不能直接对外报价。

请财务/采购按下面三张模板提供 CSV，导入后跑 `check_prices`，全部 `real` 才能开放正式报价。

## 1. 材料价（materials）

字段：`material_code,price_per_kg,currency,effective_from,source,note`

```csv
material_code,price_per_kg,currency,effective_from,source,note
A105,7.20,CNY,2026-01-01,purchase,2026年采购价
F304,28.00,CNY,2026-01-01,purchase,
F316L,35.00,CNY,2026-01-01,purchase,
```

- `source` 必须是 `purchase` / `market` / `manual`，**不能是 demo**；
- 同一材质同一生效日只能一条；
- 价格口径统一为“元/kg，含税/未税”在 note 里写明（建议全公司统一一种）。

## 2. 工艺费率（rates）

字段：`code,label,unit,rate,tiers,effective_from`

```csv
code,label,unit,rate,tiers,effective_from
machining,加工,per_piece,0,{"50":18,"100":28,"300":45},2026-01-01
surface,表面处理,per_piece,0,,2026-01-01
packaging,包装,per_piece,0,,2026-01-01
inspection,检测,per_piece,0,,2026-01-01
freight,运费,per_kg,0,,2026-01-01
mgmt,管理费,percent,6,,2026-01-01
```

- `tiers` 的键用数字字符串（如 `"50"`），不要写 `<=50`；导入命令会规范化；
- `unit`：`per_piece` / `per_kg` / `percent` / `per_hour`；
- 六个 code 必须有真实生效记录，否则快照会标 `demo_mixed`。

## 3. 客户（customers）

字段：`code,name,level,discount_pct,currency,payment_terms,active`

```csv
code,name,level,discount_pct,currency,payment_terms,active
C001,示例客户,A,8,CNY,30%预付+发货前付清,1
```

- `discount_pct` 0–30，系统合并上限 50%；
- 客户折扣只在 API 未显式传 discount 时自动带入。

## 4. 其他必须确认的参数

| 参数 | 谁给 | 说明 |
|---|---|---|
| 利润率 / 管理费率 | 财务 | 当前演示 12% / 6% |
| 税率 | 财务 | 当前 13%，含税/未税口径 |
| 汇率 | 财务 | 当前 7.10；USD 报价按报价日 |
| 折扣红线 | 销售经理 | 当前 >5% 需审批 |
| 大额红线 | 财务 | 当前 >5 万需审批 |
| 毛利率红线 | 财务 | 当前 <8% 需审批 |
| 交期规则 | 工艺 | 当前按规格档位演示 |

## 5. 导入与验证

```bash
# 生成模板（也可以直接用 quote/fixtures/csv/ 下的文件）
python manage.py import_prices --kind materials --template -
python manage.py import_prices --kind rates --template -
python manage.py import_prices --kind customers --template -

# 导入（先 dry-run）
python manage.py import_prices --kind materials --file materials.csv --dry-run
python manage.py import_prices --kind materials --file materials.csv --strict

# 生产门：必须全部 real
python manage.py check_prices
```

## 6. UAT 需要的历史报价

请提供 20 张历史报价（脱敏即可），字段至少：

`标准/类型/等级/口径/材质/数量/表面/包装/检测/运费/折扣/成交价/日期`

我们会回放并比对金额；差异 >0.5% 的逐项解释。销售/财务/经理签字后才能上线。
