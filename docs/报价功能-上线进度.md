## 3. 动态价格参数（已实现）

材料价/工资率已改为**报价参数**：默认从价格库/档位带出，每单可覆盖 `params.material_price_per_kg` / `params.machining_rate`，保存时写入快照；旧报价不受新价格影响。

## 4. 剩余 P0：默认参数 + UAT

动态参数已支持，不再要求一张永久固定价目表；但生产仍需要一组初始默认参数（或要求每单填写），且当前 dev 库默认值仍是演示数据：

```text
check_prices -> exit 2
材料价 23/23 source=demo
工艺费率 6/6 source=demo
failures = 29
```

需要财务/采购提供（作为默认参数，可后配置）：

1. 初始材料价（元/kg、生效日期）；
2. 初始工资率/工艺费率（加工/表面/包装/检测/运费/管理，档位）；
3. 客户与默认折扣；
4. 利润率、管理费率、税率、汇率、折扣/大额/毛利红线；
5. 20 张历史报价用于 UAT。

每张报价单仍可填本次实际价，默认参数只做带出和基准。

模板和导入步骤：[报价上线-待提供数据清单](报价上线-待提供数据清单.md)

导入后必须：

```bash
python manage.py import_prices --kind materials --file materials.csv --strict
python manage.py import_prices --kind rates --file rates.csv --strict
python manage.py import_prices --kind customers --file customers.csv --strict
python manage.py check_prices      # 必须 exit 0
python manage.py seed_roles        # deploy.sh 已自动执行
```
