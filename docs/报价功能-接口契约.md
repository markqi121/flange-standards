# 报价功能 · 接口契约 v1.0

> 本文件是 `quote` 应用 Wave 0 的冻结契约。backend-core、pricing-data、web-ui 都以本文件为准；
> 需要改字段/接口时先改契约并经 Lead 确认，不能各自改一套。

## 1. 边界

- `catalog`：只读标准库，不修改；`quote` 通过外键引用 `catalog.DimensionRow` / `Standard` / `Rating`。
- `quote`：报价、价格库、客户、快照、审批、PDF/Excel、权限。
- 金额用 `Decimal`（14,2），重量用 `Decimal`（10,3）或 Float（存储 3 位）；尺寸沿用 catalog 的 Float。
- 时间 `Asia/Shanghai`；报价日期用本地日期。

## 3. 服务接口（quote/services.py 等）

### 3.1 重量

```python
resolve_weight(row, material, c_includes_f=False) -> WeightResult
# WeightResult:
# net_weight: Decimal, source: "standard"|"geometry", confidence: "B"|"C",
# volume_mm3, parts, density, rule_version, raw_weight
```

- 有 `row.weight`：按材质密度/7.85 修正，source=standard，confidence=B；
- 无：几何计算 + 校准，source=geometry，confidence=C；
- 重量规则 `w0.3`。

### 3.2 计算

```python
calculate(input: dict, *, user=None) -> dict
```

输入：

```json
{
  "std": "asme-b16-5", "type": "weld-neck", "size": "4",
  "rating": "150", "material": "A105", "qty": 10,
  "design_temp_c": 38, "design_pressure_bar": 16,
  "surface": "none", "packaging": "wood",
  "inspections": ["pmi"], "freight_per_kg": 0.6,
  "discount_pct": 0, "currency": "CNY", "fx_rate": 7.10,
  "params": {"yield": 0.70, "machining_factor": 1.0,
             "management_pct": 6, "profit_pct": 12, "tax_pct": 13,
             "material_price_per_kg": 7.35, "machining_rate": 48}
}
```

输出：

```json
{
  "item": {"description": "...", "standard_edition": "...", "material": "...",
           "size_label": "4″", "rating_label": "Class 150", "qty": 10,
           "net_weight": 6.800, "weight_source": "standard",
           "weight_confidence": "B", "lead_time_days": 8},
  "costs": {"material": 69.94, "machining": 20.70, "surface": 0,
            "inspection": 0, "packaging": 35, "freight": 4.08,
            "management": 7.78, "total": 137.51},
  "price": {"unit_net": 150.93, "unit_tax": 19.62, "unit_gross": 170.55,
            "amount_net": 1509.30, "tax_amount": 196.20,
            "total_gross": 1705.50, "margin_pct": 8.9, "per_kg": 25.08},
  "validation": {"status": "pass", "messages": [],
                 "pt": {"status": "pass", "allowed_bar": 19.6, "material_group": "1.1"}},
  "approval_required": false,
  "snapshot": {"params": {"material_price_per_kg": 7.35,
                           "material_price_source": "manual",
                           "machining_rate": 48,
                           "rate_source": "manual_override"},
               "standard_editions": {}, "price_versions": {}, "weight_rule": "w0.3"}
}
```

- 所有金额先按 Decimal 计算，最后 2 位；重量 3 位。
- **动态参数**：`params.material_price_per_kg`、`params.machining_rate` 是“本次报价实际值”，可覆盖价格库/档位；不传则用价格库默认；保存时写入 `CostSnapshot.params`，并标 `material_price_origin=manual` / `rate_source=manual_override`（`material_price_source` 保留库价原来源）。
- `amount_net = round(unit_net * qty)`；`unit_gross = unit_net + unit_tax`；保证单价×数量与总额一致。

## 4. 状态机

```
draft --submit--> pending_approval --approve--> approved --send--> sent
draft --submit(auto)--> approved            sent --accept--> accepted --order--> ordered
pending --reject--> draft                    sent --reject--> rejected
sent --expire--> expired                     any --cancel--> cancelled
```

- 未触发红线：draft→approved（自动）；
- 触发：discount>5%、total>50000、margin<8%；
- `rejected` 后可复制为新报价。

## 5. 权限（Django Groups）

| 组 | 权限 |
|---|---|
| `sales` | 建/改本人草稿、查看本人报价、查看自己报价毛利；不看成本明细，不能改材料价/工资率 |
| `engineering` | 查看成本/重量/工艺参数；只读报价 |
| `finance` | 价格库读写、成本/毛利查看、审批财务；可覆盖本次材料价/工资率 |
| `sales_manager` | 全部报价、审批、折扣 |
| `quote_admin` | 全部 + 价格库 + 标准库只读 + 用户权限 |

- 未登录：无 `/quote/*`；
- `/admin/` 仅 `quote_admin`；
- 成本明细接口/页面按组限制。

## 10. 动态价格参数（2026-11-06 新增）

- 材料价、工资率是**报价时参数**，不是长期主数据；
- 价格库 `MaterialPrice` / `ProcessRate` 只提供默认值和审计基线；
- 每张报价可传 `params.material_price_per_kg` / `params.machining_rate` 覆盖；
- 覆盖值写入成本快照，旧报价不受后续价格库变更影响；
- 覆盖权限：engineering / finance / sales_manager / quote_admin；sales 只能使用默认值；
- 偏差 >5% 或毛利率 <8% 仍走审批红线（后续可加“本次价 vs 基准价”偏差审批）。

## 11. 变更流程

- 改契约 → Lead 确认 → 更新本文档版本号；
- 改 models 只能 backend-core，迁移由 backend-core 生成；
- 改 UI 只能 web-ui；
- 改价格/客户/admin 只能 pricing-data；
- QA 不直接改业务代码。
