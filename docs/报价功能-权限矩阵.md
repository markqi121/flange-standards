# 报价功能 · 权限矩阵（T7）

> 对应契约 §5。实现文件：`quote/permissions.py`（能力判定）、`quote/api.py`（API 强制）、
> `quote/services.py`（数据范围 helper）、`quote/management/commands/seed_roles.py`（角色组种子）。
> 测试：`quote/tests_permissions.py`。

## 1. 角色与数据范围

| 角色（Django Group） | 说明 | 报价数据范围 | 成本/毛利 | 价格库 | 审批 | 建单 |
|---|---|---|---|---|---|---|
| `sales` | 销售 | **仅本人创建** | 只看毛利，**不看成本明细** | 只读页面，不可改 | ✗ | ✓ |
| `engineering` | 技术 | 全部（只读） | 成本/重量/工艺参数全部可见 | 只读 | ✗ | ✗ |
| `finance` | 财务 | 全部（只读） | 可见 | **读写** | ✗ | ✗ |
| `sales_manager` | 销售经理 | 全部 | 可见 | 只读 | **✓** | ✓ |
| `quote_admin` | 报价管理员 | 全部 | 可见 | 读写 | ✓ | ✓ |
| `superuser` | Django 超级用户 | 等价 `quote_admin` | 可见 | 读写 | ✓ | ✓ |

多组用户按最高权限角色生效：`quote_admin > sales_manager > finance > engineering > sales`。
未登录：所有 `/quote/*` 与 JSON API 返回 403。

## 2. 能力矩阵（`quote/permissions.py`）

| 能力函数 | sales | engineering | finance | sales_manager | quote_admin | superuser |
|---|---|---|---|---|---|---|
| `can_view_cost` | ✗ | ✓ | ✓ | ✓ | ✓ | ✓ |
| `can_edit_prices` | ✗ | ✗ | ✓ | ✗ | ✓ | ✓ |
| `can_approve` | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |
| `can_create_quote` | ✓ | ✗ | ✗ | ✓ | ✓ | ✓ |
| `can_view_all_quotes` | ✗ | ✓ | ✓ | ✓ | ✓ | ✓ |
| `can_view_quote(user, quote)` | 仅本人 | ✓ | ✓ | ✓ | ✓ | ✓ |
| `can_transition(user, quote, action)` | 本人非审批动作 | ✗ | ✗ | 全部动作 | ✓ | ✓ |

状态动作：`submit / approve / reject / send / accept / order / expire / cancel`。
`can_transition` 只判断角色与归属，具体状态是否允许仍由 `services.transition` 校验（非法流转 409）。

## 3. 页面 / API 矩阵

| 入口 | 未登录 | sales | engineering | finance | sales_manager | quote_admin |
|---|---|---|---|---|---|---|
| `/quote/` 工作台 | 403/登录 | ✓ | ✓（只读） | ✓（只读） | ✓ | ✓ |
| `/quote/list/` 列表 | 403/登录 | 仅本人 | 全部 | 全部 | 全部 | 全部 |
| `/quote/<no>/` 详情 | 403/登录 | 仅本人 | 全部 | 全部 | 全部 | 全部 |
| `/quote/<no>/print/`、`/pdf/` | 403/登录 | 仅本人 | 全部 | 全部 | 全部 | 全部 |
| `/quote/prices/` 价格库 | 403/登录 | 只读 | 只读 | 读写 | 只读 | 读写 |
| `GET /quote/options/` | 403 | ✓ | ✓ | ✓ | ✓ | ✓ |
| `POST /quote/calc/` | 403 `auth_required` | ✓ 但**剥离 costs** | ✓ 全量 | ✓ 全量 | ✓ 全量 | ✓ 全量 |
| `POST /quote/` 创建 | 403 | ✓ | 403 `permission_denied` | 403 | ✓ | ✓ |
| `POST /quote/<no>/status/` | 403 | 本人非审批动作 | 403 | 403 | ✓ | ✓ |

### 成本防泄露（API 层）

无 `can_view_cost` 的角色（如 `sales`）调用 `/quote/calc/` 时：

- 删除顶层 `costs`（材料/加工/表面/检测/包装/运费/管理费）；
- `snapshot.params` 只保留白名单字段（报价参数、demo 标记、税率/利润/折扣），
  剥离 `material_price_per_kg`、成本参数、`rate_versions` 等；
- `snapshot.price_versions` 置空；
- 保留 `price`（含 `margin_pct`，契约允许销售看本人毛利）、`validation`、`weight`、`item`。

创建/状态接口返回的 `quote.items[*]` 对无成本权限角色同时隐藏 `material_price`。

## 4. 角色创建（幂等）

```bash
.venv/bin/python manage.py seed_roles            # 创建/收敛 5 个 Group 与权限
.venv/bin/python manage.py seed_roles --dry-run  # 只打印，不写库
```

- 可重复执行；每次按规格 `permissions.set(...)` 收敛，不会重复建组。
- **上线必跑**：跑过 `seed_roles` 后，`quote/permissions.py` 的兼容模式关闭，
  未加入任何角色组的登录用户按“无权限”处理（看不到成本、不能建单/审批）。
- 兼容模式：数据库里一个角色组都没有时（尚未 seed），能力判定退回 T7 之前
  “登录可用”的行为，避免开发/演示环境因未初始化而全部 403。

给用户分配角色示例：

```bash
.venv/bin/python manage.py shell -c "
from django.contrib.auth import get_user_model
from django.contrib.auth.models import Group
u = get_user_model().objects.get(username='alice')
u.groups.add(Group.objects.get(name='sales'))
"
```

## 6. 运维注意

- `/admin/` 建议限制内网/VPN；`quote_admin` 组按需加入 `is_staff`。
- 角色组名是权限判定依据，**不要重命名**；新增角色需同时改 `quote/permissions.py`
  与 `seed_roles.py`，并补测试。
- 成本明细只允许 technical/finance/manager/admin 查看；发现泄露按安全事件处理。
