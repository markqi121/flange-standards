# 法兰重量 CAD 验证 SOP（可复用）

> **术语说明**：下文“标准表/参考重量”指数据包里的近似重量，不是标准强制值；来源见 [重量数据来源说明](../重量数据来源说明.md)。

> 目标：以后每改一次重量公式、加一个规格、换一个标准，都能用同一套方法证明
> **“公式算的体积 = CAD 实体体积”**，而不是靠感觉。
>
> 一句话：**公式负责报价时实时算，CAD 负责独立验算；两者用同一套尺寸，差多少一目了然。**

---

## 0. 先分清三个“重量”

| 口径 | 怎么来 | 用在哪 |
|---|---|---|
| **净重** | 标准表 / 几何体积 × 密度 | 报价单、元/kg |
| **毛坯重** | 净重 ÷ 材料利用率 | 材料费 |
| **运输重** | 净重 + 包装 | 运费 |

CAD 验证的是**净重**（实体体积 × 密度），不是毛坯重，也不是运输重。

---

## 1. C 和 f：标准已定义，数据包已归一

法兰正面有一个凸起的密封面：

```
                    ┌── f ──┐
                    │ 密封面 │   ← 凸台高度 f
        ┌───────────┴────────┴───────────┐
        │            C 法兰本体            │  ← 本体厚度 C
        └─────────────────────────────────┘
```

标准里 C 和 f 都有明确定义。**这个项目的数据包已经统一成“本体厚度 th + 密封面高度 f”**：

- `th` = 22.4（本体厚度，不含 f）；
- `rf_height` = 1.5（密封面高度）；
- 总厚 = th + f = 23.9；
- `catalog/drawings.py` 也是按 `th + f` 画总厚的。

所以**报价和验证时不需要你选 C 含不含 f**，引擎固定按这个口径。

只有一种例外：**导入旧 Excel** 时，客户表里的“厚度 C”如果不是按这个口径（比如它已经是总厚 23.9），导入时做一次列映射/减 f 即可，不改公式。

`verify_flange.py --c-includes-f` 只是给旧表核对用的数据开关，不是业务选项。

---

## 2. 这套方法验证什么、不验证什么

**能验证：**

- 公式里的环、轮毂、锥台、密封面、内孔、螺栓孔有没有漏项/多加；
- 同一组尺寸下，公式体积和 CAD 实体体积是否一致；
- 公式代码（JS/Python）有没有写错。

**不能验证：**

- 实际锻件和这个“理想几何”是否完全一样（圆角、拔模斜度、焊端坡口、RTJ 槽）；
- 标准表的近似重量是否准确；
- 实际材料密度/过磅重量。

所以顺序永远是：

```
公式 vs CAD   →   标准表 sanity check   →   实际过磅校准
```

---

## 3. 开始前确认口径

标准库数据口径已经固定，不需要每次问 C/f；需要确认的是下面这些“数据够不够”：

1. **对焊内孔 B**：当前按 Sch 40 近似；客户指定壁厚时用 `--pipe-id` 覆盖；
2. **密封面**：标准库以 RF 为主；FF/RTJ 需要补建；
3. **轮毂**：数据只有 A/H/焊接端，脚本按直锥台；
4. 单位 mm，密度 g/cm³，重量 kg。

只有导入旧 Excel 时，才需要核对它表里的“C”是不是总厚。

## 6. 批量验证

把要验的规格写进 `samples.csv`：

```csv
std,type,dn,rating,c_includes_f,export
asme-b16-5,weld-neck,100,150,0,1
asme-b16-5,slip-on,100,150,0,0
asme-b16-5,blind,100,150,0,0
en-1092-1,weld-neck,100,pn16,0,0
jis-b2220,weld-neck,100,10k,0,0
```

运行：

```bash
python verify_flange.py --batch samples.csv \
  --report batch-report.md --json batch-report.json --csv batch-report.csv
```

- `c_includes_f=1` 表示这个规格的 C 已经含 f；
- `export=1` 表示导出 STEP/STL；
- 报告会给出每个规格的公式体积、CAD 体积、误差、净重、标准表、校准后重量、结论。

## 7. 判定标准与失败排查

**通过标准：体积误差 < 0.1%。**

如果超过 0.1%，按顺序查：

| 现象 | 先查什么 |
|---|---|
| 所有对焊都差一个固定比例 | 环体积用的是 D−A 还是 D−B？漏没漏本体环？ |
| 盲板差一个固定值 | 密封面是整圆还是环？螺栓孔扣没扣？ |
| 滑套差一个固定值 | 轮毂建没建？环的内径用管外径还是内孔？ |
| 只有某个口径开始偏 | 内径/壁厚系列是不是不对？ |
| 所有规格都差 2 倍 | 单位（mm/cm/m）或直径/半径 |
| 结果 NaN/负数 | 尺寸空值、内径 > 外径、L<0 |

**不要改 CAD 去迁就公式。** CAD 是独立 oracle，公式错了就改公式；公式对了再重算校准系数。

---

## 8. 公式改了以后，校准系数怎么更新

公式变了，`CAL` 里的 c/p 必须重算：

```bash
python calibrate_weight.py --json calibration.json --md calibration.md
```

输出每个类型的 c、p、样本数、中位误差、90 分位误差。  
把新的 c/p 同步到：

- 方案 HTML 的 `CAL` 常量；
- Django 的 `quote/weight.py`；
- 重量规则版本号（`w0.3` → `w0.4`）。

校准系数只是“标准表近似/圆角/余量”的修正，不是用来掩盖公式错误的。
