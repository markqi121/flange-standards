- `ax-forge.com` 的 DNS 在 Cloudflare，但本机可用的 Cloudflare 凭据只有 Workers/Pages 权限，

- 以后想换子域名，只需加一条 DNS 记录 + 改 Nginx/环境变量（见第 7 节），应用代码不用动。

## 5. Nginx 改动

在 `/etc/nginx/sites-available/flange-site.conf`（`ax-forge.com` 的 443 server 块）里，
`location /` 之前增加了：

```nginx
location ^~ /std/static/ {
    alias /srv/flange-std/app/staticfiles/;
    expires 1h;
    add_header Cache-Control "public, max-age=3600";
    access_log off;
}

location ^~ /std/ {
    proxy_pass http://127.0.0.1:8011/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 60s;
    proxy_send_timeout 60s;
    client_max_body_size 4m;
}
```

原文件已备份为 `flange-site.conf.bak-flange-std-<时间>`。
现有 Astro 站点（`/`、`/standards/`、`/products/flanges/`）未受影响，已回归验证 200。

- 建议再同步到本机或对象存储（异地备份）。

```bash
sudo systemctl stop flange-std
sudo cp /var/lib/flange-std/backups/db-YYYY-MM-DD.sqlite3 /var/lib/flange-std/db.sqlite3
sudo chown deploy:deploy /var/lib/flange-std/db.sqlite3
sudo systemctl start flange-std
```

## 10. 手机端说明

### 10.1 打印没有反应

iPhone / iPad 的 Safari **不支持 `window.print()`**，点「打印」不会弹对话框，这是浏览器限制。
现在打印页提供：

- **下载 PDF**：服务端用 Playwright + Chromium 渲染同一张 A4 规格卡，手机点一下直接下载/分享；
- **打印**：桌面和 Android Chrome 正常；iOS 点「打印」会显示文字提示，引导用「下载 PDF」；
- **复制链接**：把地址发到电脑上打印。

PDF 首次生成约 6–7 秒（启动 Chromium + 渲染），之后同一规格走缓存约 1–3 秒；
`PDF_LAYOUT_VERSION` 变更后会重新生成。

### 10.2 手机打开速度

实测数据（2026-11-04 晚间，本机网络）：

| 路径 | 服务器本地 | 经 Cloudflare 公网 |
|---|---|---|
| 首页 | ~20 ms | 1.5–2.2 s TTFB |
| 规格卡 | ~22 ms | 1.2–1.7 s TTFB |
| CSS | ~4 ms | 2–3 s（Cloudflare HIT） |

页面本身只有约 40 KB（HTML 15 KB + CSS 30 KB + favicon），服务器响应 20 ms，
所以慢的部分主要在「用户 → Cloudflare 边缘」这段网络：

- 对 `104.21.19.198` 的 ping 约 230 ms，且有丢包；
- `curl -6` 访问 Cloudflare IPv6 地址在本网络直接超时，IPv4 可通；
- iPhone/Safari 若优先走 IPv6，会先等 AAAA 超时再回落 IPv4，体感比电脑慢。

已做的优化：

- 去掉每个页面都加载的 `print.css`（省一个请求）；
- 手机端关闭毛玻璃和首屏大面积渐变，减少绘制；
- 公开 HTML 加 `Cache-Control: public, max-age=120`，CSS 1 小时缓存，并加 `?v=` 版本号避免旧缓存；
- PDF 服务端缓存，避免重复启动 Chromium。

真要明显改善大陆手机访问，需要从网络层解决（当前没有 Cloudflare DNS 权限）：

1. 在 Cloudflare 删除/关闭该子域的 AAAA 记录，强制 IPv4；
2. 或接 Cloudflare Argo / 国内 CDN；
3. 或把站点放到大陆服务器（需要域名 ICP 备案）。
