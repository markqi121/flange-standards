# 重量公式 CAD 验证 · 4″ Class 150 对焊法兰

- 验证日期：2026-11-06
- 工具：CadQuery 2.5.2 + OpenCascade（cadquery-ocp 7.7.2）
- 样板：ASME B16.5-2025，4″，Class 150，对焊（WN），A105
- 目的：用独立 CAD 实体体积，校验重量引擎的几何体积公式

## 1. 结论

**通过。** 公式体积与 CAD 实体体积完全一致，相对误差约 `1.3e-14%`，属于浮点误差量级。

| 项目 | 结果 |
|---|---|
| 公式净体积 | 909,987.747 mm³ |
| CAD 实体体积 | 909,987.747 mm³ |
| 体积误差 | -1.3e-14% |
| 公式理论净重（7.85 g/cm³） | 7.143 kg |
| CAD 理论净重 | 7.143 kg |
| 标准表近似重量 | 6.800 kg |
| 校准后报价重量（规则 w0.3） | 6.812 kg |

说明：标准表本身是近似重量，与 CAD 相差约 5% 属正常；CAD 与公式一致说明“公式实现”正确，不说明标准表是精确值，也不说明实际锻件和这个简化模型完全一样。

## 2. 建模口径

- C = 22.4 mm（数据包归一后的本体厚度，不含 f）；f = 1.5 mm 另加，总厚 23.9 mm；
- 内孔 B 按 Sch 40（DN100 → 102.3 mm）近似；
- 轮毂按 A=134.9 → 焊接端 dw=114.3 的直锥台，长度 H−C=52.3 mm；
- 密封面按 RF 环形凸台；
- 8 × Ø19.1 螺栓孔，穿过法兰厚度 C；
- 未建圆角、焊端坡口、RTJ 环槽。

## 3. 本次发现并修正的问题

初版对焊公式用的是“环 D−A + 轮毂锥体”，漏掉了法兰本体上 **A 到 B 之间** 的一圈材料，导致 4″ 样板少算约 136,000 mm³（约 1.07 kg）。

修正为：

```
环体积 = π/4 × (D² − B²) × C
轮毂体积 = πh/12 × (A² + A·dw + dw²)
内孔扣除 = π/4 × B² × (H−C)
密封面 = π/4 × (D2² − B²) × f
螺栓孔 = n × π/4 × d² × C
```

修正后重新拟合标准表校准系数，规则版本升到 `w0.3`。
