# 数据性质、版权边界与免责声明

## 1. 这个数据包是什么

本数据包是**事实性数据的整理与结构化结果**：标准中公布的尺寸表、压力—温度额定值、材料组/材料牌号、
公差、标记要求、版本变更记录，以及项目自行撰写的说明文字（导语、读表提示、FAQ）。

它**不是**标准的电子版，也**不能**替代标准原文。

## 2. 不包含什么

- 不包含标准 PDF 文件本身；
- 不包含标准的正文段落、条款原文、图表、示意图、表格截图；
- 不包含标准发布机构的封面、版权页、标识、认证声明；
- 不包含任何用于绕过付费墙或未授权访问的内容。

数据来源是项目通过合法渠道获得的标准版本，转录时只提取事实性数据，并在每个主题的
`sources` 中保留表号/条款和 PDF 页码，便于对照原标准复核。

## 3. 版权与商标

- ASME、ASME B16.5、ASME B16.47、EN 1092-1、JIS B2220 等名称与标准文本的版权归各自发布机构
  （ASME、CEN、JSA 等）所有。
- 本数据包与上述机构无隶属、合作或背书关系；不得暗示标准发布机构对本数据包或使用本数据包的产品
  作出认可。
- 事实性数据本身在不同法域下的可版权性不同；**将本数据包对外再分发、商业销售或嵌入对外产品前，
  请自行确认许可与合规要求**，必要时取得标准发布机构的授权或法律意见。

## 4. 使用建议

- 用于站内/产品内的标准数据查询、选型预筛、报价辅助时，页面或接口上应同时展示：
  - 标准版本（如 `ASME B16.5-2025`）；
  - 数据核对日期（`verifiedOn`）；
  - 来源表号/页码（`reference_source`）；
  - 声明：**「数据仅供参考，以购买的标准版本为准」**。
- 不要把本数据包当作标准原文的替代品提供给客户下载；如需标准全文，请通过官方渠道购买或合法获取。
- 修改数据时保留 `edition`、`verifiedOn`、`sources` 字段；这三个字段是数据可信度的组成部分。

## 5. 免责声明

- 数据按「现状」提供。虽然已逐单元格转录并做过交叉核对，但**不保证**与任何特定版本的标准完全一致，
  也不保证适用于特定工程、压力等级、温度区间或材料组合。
- 尺寸、压力额定值和材料选择必须由有资质的工程师按项目适用的标准版本复核；因使用本数据包产生的
  设计、制造、采购或安全后果，由使用者自行承担。
- 标准会改版（例如 ASME B16.5-2025 已替代 2020 版）。使用前请确认采购技术规格书要求的是哪一版。

## 6. 如何合法获取标准

- 从标准发布机构（ASME Store、CEN 成员国标准机构、JSA 等）购买；
- 使用发布机构提供的免费预览/阅读服务；
- 通过所在国法规引用的公开渠道（如美国 IBR 相关公开副本）；
- 通过企业或高校图书馆的标准数据库。

站点 `docs/standards/acquisition-guide.md` 有更详细的合法获取路径说明。
